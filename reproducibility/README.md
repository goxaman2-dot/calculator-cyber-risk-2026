# Расчётный комплект к статье «Пороговое бюджетирование защиты информации малого предприятия: достижимость приемлемого ущерба и устойчивость к ошибкам оценки эффективности мер»

Авторы: И. В. Мандрица, О. В. Мандрица (СКФУ).

## Состав

| Файл | Назначение |
|---|---|
| `data.json` | Снимок параметров модели из калькулятора «КиберСмета» (файл `отчеты о киберугрозах/Ландшафт ущерба и бюджета 2023–2026_ 3D-модель.html`): 18 классов угроз по шести узлам времени (x, z, ρ, ρ₀, g, k, доли фактических затрат), 13 отраслевых профилей ОКВЭД 2, каталог 19 мер и их связь с угрозами, частоты 2024 г. с источниками |
| `analysis.py` | Все расчёты статьи: нормативы при двух мерах ущерба (табл. 1), точный минимум и жадный алгоритм (табл. 3), запас достижимости и чувствительность (табл. 4), классы достижимости и устойчивые нормативы (рис. 3, 5, табл. 5), правила распределения и надёжность закрытий внутри и строго вне Θ с бутстреп-интервалами (табл. 6, рис. 6–7), портфель мер с полным перебором 2^19 наборов (табл. 7), чувствительность к Dₐ, ранговые корреляции 2024 г. |
| `figs2.py` | Построение рисунков 2, 3, 5, 6, 7 (SVG) по `res.json` |
| `requirements.txt` | Версии библиотек |

## Запуск

```
pip install numpy scipy
python analysis.py        # около 10 с; создаёт res.json
python figs2.py           # нужен figs.py с помощниками рисования из каталога статьи
```

## Параметры, зафиксированные в коде

- Точечные значения: Emax = 0,85; EC50 = 0,30; h = 1,5; Dₐ = 0,12; MTTD = 30 сут.; бюджет 300 тыс. руб.; L = 3000 тыс. руб.; K_R = 84,5 тыс. руб.; ȳ = 1,5.
- Θ: Emax ∈ [0,75; 0,95], EC50 ∈ [0,20; 0,40], h ∈ [1,2; 1,8].
- Расширенный параллелепипед: Emax ∈ [0,70; 0,95], EC50 ∈ [0,15; 0,50], h ∈ [1,0; 2,5]; сценарии «строго вне Θ» — выборка из него с отбрасыванием точек Θ.
- Распределение параметров — равномерное, независимое. Генераторы: `default_rng(7)` (базовые прогоны), `default_rng(2026)` (2000 + 2000 сценариев надёжности, бутстреп 1000 повторений).
- Сетка бюджета — 300 порций; проверка — 600 и 900.
