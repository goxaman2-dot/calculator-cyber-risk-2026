# Информационная Безопасность - МСП

**ИБ-МСП** — прототип калькулятора остаточного информационного риска для малого и среднего предпринимательства.

Калькулятор рассчитывает эффективность затрат на меры защиты, и не использует инвестиционную логику. Информационная безопасность рассматривается как защитная функция бизнеса: она не создаёт самостоятельный актив, а требует плановых, превентивных, правовых, обнаруживающих и восстановительных затрат для снижения остаточного риска.

## Что считает калькулятор

- исходный информационный риск;
- остаточный риск после фактических защитных затрат;
- остаточный риск по трём слоям:
  - технический слой;
  - организационно-правовой слой;
  - экономико-управленческий слой;
- правовой риск несоблюдения режима обработки информации;
- индекс критического ущерба относительно порога устойчивости МСП;
- первоочередные меры по снижению остаточного риска;
- портфель дополнительных защитных затрат при заданном пределе бюджета.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

```text
app.py              интерфейс Streamlit
data_catalog.py     активы, угрозы, меры, отраслевые профили
risk_engine.py      расчётное ядро остаточного риска
requirements.txt    зависимости
METHODOLOGY.md      методологическая записка
```

## Важное ограничение

Калькулятор является исследовательским прототипом. Он не заменяет технический аудит, юридическое заключение, судебную оценку, страховой расчёт или расследование инцидента.
