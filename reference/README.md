# Справочные материалы

Рабочие материалы, перенесённые из личного архива автора (не публиковались, не входят в расчётный код калькулятора). Собраны по трём направлениям, актуальным для развития модели.

## vendors/ — вендоры и цены мер защиты

- `Модель_16_факторов_с_УБИ_и_РУС.xlsx` — по каждому из 16 доменов угроз: бюджетное и VIP/Enterprise-решение с конкретным вендором и ценой (Yandex Security Center, Kaspersky Hybrid Cloud, PT App Firewall, Solar inRights и др.), привязано к перечню УБИ ФСТЭК.
- `Модель_16_факторов_новая_нумерация_Delphi_MC.xlsx` — та же модель факторов плюс листы с Дельфи-оценками экспертов и симуляцией Монте-Карло.

## threat-landscape/ — ландшафт угроз и источники регистрации инцидентов

- `thrlist.xlsx` — прямой экспорт из Банка данных угроз (БДУ) ФСТЭК.
- `Метрика_БДУ_227_ГОТОВО.xlsx`, `BDU_227_Токсичность_по_экотипам.xlsx` — производные метрики токсичности по 227 угрозам БДУ, Парето-ядро 80%.
- `Кластеризация угроз Банка данных ФСТЭК...docx`, `vak_article_threat_grouping_method.docx` — методы группировки угроз БДУ (интегральный индекс токсичности; двухкритериальная кластеризация CVSS+частота).
- `СТАТЬЯ индекс Парето 2026.docx`, `Генезис ландшафта киберугроз...docx` — обзоры динамики ландшафта угроз с прогнозом на 2026 год, ссылки на Verizon DBIR, Positive Technologies, ГосСОПКА, FinCERT.
- `Таблица 2027 атак и угроз ФСТЭК.docx` — перспективные классы атак, ещё не включённые в реестр УБИ.
- `Опорный_каркас_HIJK_заполнен.xlsx` — авторский каркас источников ландшафта угроз с рейтингом достоверности.
- `Pareto_Index_2023_2026_Прогноз_AI (1).xlsx` — динамика индекса токсичности и Парето-ядра по годам 2023–2026.

## tail-risk-math/ — математика тяжёлых хвостов и когерентности атак

- `epidemic_threat_model_VAK.docx` — формула хвоста обобщённого распределения Парето (GPD) для отдельных угроз + модель когерентности атак (коэффициент K_coh, когерентное Парето-ядро).
- `NTI_PhaseTransition_Cyber_Mandritsa_2026.docx` — теория экстремальных значений (EVT), оценка хвостового индекса методом Хилла.
- `ЧАСТЬ_I_T_bind_ДИЛОГИЯ_ВАК.docx` — модель T_bind с коэффициентом синергии K_syn для совместно реализуемых угроз, эмпирическая проверка на 40 инцидентах.
- `Mandritsa_TSU_math_article_v2.docx` — модель угрозы как дискретно-стохастического оператора, «тяжёлый восстановительный хвост» ущерба.

## Статус

Материалы пока не интегрированы в расчётный код (`risk_engine.py`, `data_catalog.py`) — это справочная база для следующего шага разработки.
