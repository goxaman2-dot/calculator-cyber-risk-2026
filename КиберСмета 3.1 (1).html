Меры защиты и вендоры

Меры подбираются одним из двух методов. Метод PARETO‑X ищет минимальные затраты, при которых закрыты все угрозы Парето-ядра и остаточный риск не выше нормы. Метод ALE–ROSI набирает меры по убыванию снижения потерь на рубль затрат. Для каждого фактора есть три уровня решения. Цены являются ориентирами каталога на 03.11.2026 (₽ в год, без НДС) и требуют сверки с прайс-листами на дату заключения договора; цену выбранного варианта можно исправить прямо в карточке.

Как рассчитывается
λi0 = Λ · TDIi / ΣTDI,  λi = (k · λi0 + ni) / (k + N),  TDIi* = TDIi · λi / λi0  (8)

где N — число анкет (организаций-лет), ni — число инцидентов по фактору i (по самому серьёзному инциденту анкеты; остальные инциденты распределяются пропорционально), k — вес модели в эквивалентном числе наблюдений. Пока анкет мало, оценка остаётся близкой к модели 2024 г.

L = D + Cв + m · (R/H) · (Tп + α · Tд) + w · (Nз · Tп + Nз · β · Tд),  Cв = c · Tв + счета + замена  (9)

Проверка согласованности: ранговая корреляция Спирмена между рангами TDI и рангами наблюдаемых частот по факторам; рассчитывается при N ≥ 20. Медианы ущерба показываются для факторов, где не меньше 5 ответов.
